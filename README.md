# 🔐 Password Strength Checker
### DecodeLabs Cybersecurity Internship — Project 1

## 📌 About
A fully functional Password Strength Checker web application built as part of my Cybersecurity Internship at DecodeLabs.

## 🚀 Features
- ✅ Real-time password strength evaluation
- ✅ Minimum length validation
- ✅ Uppercase & lowercase detection
- ✅ Numbers & special character checking
- ✅ Common password detection
- ✅ Live strength bar (Very Weak → Strong)
- ✅ Security recommendations

## 🛠️ Tech Stack
- Python
- Flask
- HTML & CSS
- JavaScript

## ▶️ How to Run
```bash
pip3 install flask
python3 Password_checker.py
```
Then open: http://127.0.0.1:5000
