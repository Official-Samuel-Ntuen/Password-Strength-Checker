## 🎯 About The Project

This project was built as part of my **Cybersecurity Internship at DecodeLabs (Batch 2026)**.

As a Junior Security Analyst, Project 1 focuses on the **defensive phase** of cybersecurity — understanding how weak passwords are one of the biggest vulnerabilities in any system. According to the Verizon DBIR report, **81% of hacking-related breaches leverage weak or stolen passwords.**

This web application solves that problem by giving users **instant, intelligent feedback** on their password security before it becomes a liability.

---

## ✨ Features

| Feature | Description |
|--------|-------------|
| 🔴 Real-time Analysis | Password is evaluated as you type |
| 📏 Length Validation | Minimum 8 characters enforced |
| 🔠 Character Checks | Uppercase, lowercase, numbers & symbols |
| 🚫 Common Password Detection | Blocks frequently breached passwords |
| 📊 Strength Meter | Visual bar showing Very Weak → Strong |
| 💡 Smart Recommendations | Tells you exactly what to improve |

## 🛠️ Tech Stack

- **Backend:** Python, Flask
- **Frontend:** HTML5, CSS3, JavaScript
